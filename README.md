# NutriAR - Prueba de Concepto (Entrega 1)

## Instalación
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv` y activarlo.
3. Instalar dependencias: `pip install -r requirements.txt`
4. Crear un archivo `.env` en la raíz con las variables:
   TELEGRAM_TOKEN="tu_token"
   GROQ_API_KEY="tu_api_key"

## Ejecución
Ejecutar `python bot.py` e interactuar con el bot en Telegram.
